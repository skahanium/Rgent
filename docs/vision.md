# 理念与远期

## 这是什么

Rgent 是本机桌面 Agent 客户端，跑在用户的 Windows 与 macOS 上。

它不是又一个聊天网页，也不是自研的模型调度框架。驾驶舱是 Flutter 窗口；发动机是 Python 里的 [Pydantic AI](https://ai.pydantic.dev/)，能力来自官方 [Harness](https://github.com/pydantic/pydantic-ai-harness) 积木。产品要做的是让人在这台电脑上：**选厂商和模型、圈定工作区、让 Agent 干活、写文件前过目、事后还能翻任务历史。**

## 理念

- **驾驶舱，不是第二套内核。** 暂停、确认、模型流用库已有的 HITL 与 `run_stream`。Rgent 负责窗口、多任务、恢复、工作区围栏和历史，不负责再造一遍 Agent 循环。
- **可控先于万能。** 手出不了你指定的工作区；写文件必须过目。读自动。联网默认开但有应用级总闸。不靠「更多自动」当卖点，也不把工作区里的写操作偷偷做掉。
- **本机优先。** 任务历史默认不出这台机器，不搞账号云同步。密钥进系统凭据库，不进 Git、不进工作区、不进会话库。大体积数据放在用户自选目录，避免默认堆满系统盘。
- **可换厂商。** 用户按「厂商 + 模型」选择。适配差异（官方供应商前缀、OpenAI 兼容地址等）停在发动机里，界面不出现某一家 SDK 的拼法。

## 远期目标

做成可安装的成熟 Win / macOS 客户端：多工作区、多任务并行、带历史（普通 / 归档 / 删除）、写文件过目、厂商可切换。安装包、签名、商店分发是以后才跨的线；现在仍是源码工程（Flutter 与 Python 两个进程），但运行形态指向窗口，而不是长期泡在终端里。

## 非目标

下列事项不是当前方向，施工时不要当成默认能力往上堆：

- 网页应用、把 `to_web()` 当正门、Electron / 浏览器套壳  
- 用 Qt、Flet 或经典系统控件当壳（已选正统 Flutter）  
- 账号体系、任务历史云同步  
- v0 提供命令（Shell）能力  
- 整包挂上 Harness 的 `Coder()`，把产品做成官方编码 Agent 的套壳  
- 自研一套与 Pydantic AI 平行的事件内核、工作流引擎或 LLM SDK  
- 默认引入 Temporal、云沙箱、浏览器自动化等 Harness extra  
- Linux、移动端、服务器多租户  

未锁的实现（本机接口具体形态、库引擎点名、界面页面结构等）见 [已拍板决定](decisions.md) 末节，不要在理念里提前写死。
