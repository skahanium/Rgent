# 理念与远期

## 这是什么

Rgent 是 AI 原生的单机笔记兼资料库。

Markdown 是真相。AI 写在文档里，不是旁边再开一个聊天室，也不是通用 Agent。

## 理念

- **没密钥仍是完整笔记。** 看、写、搜、文件树照常。只是 `/` 和模型相关能力不可用。
- **库就是磁盘文件夹。** Finder、别的编辑器碰到的就是同一批文件。应用不当第二份主存储。
- **门禁挡模型，不挡人。** 禁止触碰、必须遵循只锁 AI。人能打开、能搜到禁区。
- **可控先于万能。** 无 Shell。删文件要人点头。不无人值守。

细则见 [已拍板决定](decisions.md)。动手顺序见 [施工图](build.md)。

## 远期目标

做成可安装的 macOS 与 Windows 客户端。打开自选库就能记笔记；配了密钥，才能在当前这篇里用 `/`。

安装包、签名、商店分发以后再说。

## 非目标

施工时不要当成默认能力往上堆。完整合同见 [已拍板决定](decisions.md)。

- 通用 Agent 驾驶舱、独立聊天区
- Flutter / Python 边车
- 向量检索、多库并行、第二份浏览器
- 无人值守外循环
- 一键纯源码、应用内历史版本、把库绑成 git
- Linux、移动端、账号云同步
