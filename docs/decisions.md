# 已拍板决定

本文是围栏对照表。改产品性格先改这里，再改 [架构](architecture.md) / [施工守则](handbook.md) 和代码。

只收录讨论里已经点头的结论。「进了工作区就全自动」等已收回的说法不算数。

文中 **v0** 指围栏内第一代可演示客户端，不是商店版本号。

## 1. 大脑

- 驾驶舱与发动机分开：界面不直接调模型。  
- 不自研暂停 / 确认 / 事件内核。对内使用 Pydantic AI 的 `run` / `run_stream` 与 HITL（待确认以 `DeferredToolRequests` 结束，确认后带 `deferred_tool_results` 再 `run`）。  
- 事件的第一服务对象是当时的界面；档案从同一过程里留存，不为档案单做一套协议。  
- 一次 `run` 跑到需要人拍板为止；同意或拒绝是另一次调用。  
- 正在交互的那一次，真相在当前进程内存；关机或误关后待确认不能蒸发，用检查点恢复。检查点是会话数据的一部分，住在数据目录的本机库里，不是工作区里另藏一套文件。  
- 从第一天允许多个任务并行，也允许多个暂停中的任务。暂停清单来自本机库；点开某一个再灌回内存。  

Flutter 入场后：驾驶舱是 Dart 进程，发动机是 Python 进程，中间是本机接口。接口仍是薄封装，不是第二套 Agent 内核。

## 2. 选型

- 发动机：Pydantic AI。新能力先问官方链有没有，不为「更灵活」再引平行的 Agent 框架或服务端编排（如 Temporal）。  
- 能力：Harness 积木，不整包 `Coder()`；需要哪块挂哪块。Harness 的可选 extra（浏览器、云沙箱、ACP 等）默认在边界外，要开则先改本文。  
- 平台：常见 Windows 与 macOS。不做 Linux / 移动端承诺。具体系统最低版本未锁。  
- 安装包、签名、安装器：以后发版再跨，现在仍是 Python + Flutter 源码工程。  
- 密钥：系统凭据库（Windows 凭据管理器、macOS 钥匙串）。第一次在窗口里保存，以后自动读。环境变量仅可选覆盖，不是正式存储。  
- 壳：**正统 Flutter（Dart 写界面）**。不是 Flet、不是 Qt、不是网页壳。  
- 依赖只补发动机没有的驾驶舱缺口（凭据库、会话库、窗口、本机接口）。不为预留提前加库。  

## 3. 安全

- Agent 只能动用户指定的工作区；指定之外当不存在。  
- 可同时有多个工作区，各算各的围栏。  
- 联网指「除模型 API 外，Agent 还可以访问网络」，不是「网络长在文件夹里」。默认开，**应用级**总闸可关。关掉则只剩模型 API。须明白：联网开着时工作区内容可能被带出机器。  
- 读和工作区里的只看：自动。**写文件必须过目。** 减少确认靠少弹无关窗（v0 无命令），不是把写操作免掉。  
- v0 **没有命令（Shell）能力**，避免用命令绕过写文件过目。跑命令以后单独开边界讨论。  
- 同一工作区同时只允许一个任务写；其余排队或只能读。跨工作区可以同时写。  

## 4. 数据

- 工作区文件属于用户。Rgent 不当主副本，也不把产品数据写入工作区（以免进 Git）。  
- 密钥不属于业务档案，只在凭据库。  
- 配置（工作区列表、默认厂商与模型、联网总闸等）可备份，不含密钥；与会话同住数据目录（是否与会话同一个库文件未锁）。  
- 任务带历史：做完的也能点开看对话、拟写与确认。默认只在这台机器，不上传、不自动同步。  
- 三级：  
  - **普通会话**不过期，归档须用户手动点。进行中与待确认的任务留在普通里，不得被归档上限或删除清理误伤。  
  - **归档会话**有上限；超出则最旧的进入删除。界面须说清「档案柜满了，最旧的进回收站」，避免被当成丢失。  
  - **删除会话**再留一段时间后才真正去掉。  
- 普通会话若从不归档会一直占空间：这是把清理权交给人，不是机制失效。  

## 5. 存储

- 大体积数据（会话、配置、归档 / 删除）放在**第一次运行用户选定的数据目录**，可以在非系统盘。不要默认把会话堆进 `AppData` / `~/.rgent` 当唯一选择。  
- 系统盘只再留必要的小指针：记住数据目录在哪。  
- 所有会话由**一个本机库**管理，不是一会话一文件夹。具体引擎未锁。  
- 密钥不进这个库。  

## 6. 前端

- 本机窗口，Win + macOS。  
- 正统 Flutter / Dart 画界面；Python 只跑 Agent。  
- 观感走自绘现代 UI，不走 Qt Widgets、不走经典系统控件、不走浏览器套壳。  
- 第一次运行：在窗口里选定数据目录，并保存厂商密钥（写入凭据库）。  
- 开发期源码运行两个进程；捆成安装包是以后的线。  

## 明确未锁

下列不要写成已经定案：

- 本机接口的具体形态（管道、本地端口等）  
- 本机库的具体引擎（例如是否 SQLite）  
- 配置与会话是否同一库文件  
- 归档上限条数、删除会话保留多久  
- 第一批挂上的 Harness 积木清单（除已禁止 v0 Shell 外）  
- Flutter 页面结构、主题与导航  
- Windows / macOS 最低系统版本、Flutter 发布渠道  
- 更换数据目录时的搬家向导  
- 导出历史、跨机器迁移  

未锁项要落成围栏时，先改本文再施工。
