# 已拍板决定

本文是总账。改产品性格先改这里，再改 [理念](vision.md) / [架构](architecture.md) / [施工守则](handbook.md) 和代码。

只收录已经点头的结论。数字和禁令以本文为准。其它篇用链接指向这里，不要再抄一份。

文中 **v0** 指围栏内第一代可演示客户端，不是商店版本号。

## 1. 原则门

破了就不是这个产品。

- 第一次打开必须先选一个文件夹当库。空的也行。不选进不去。
- 文件夹不见了（改名、挪走、盘拔了），下次打开停在选库。让人重新指。不偷偷另起一个空库。
- 没配模型密钥仍是完整笔记：看、写、搜、文件树照常。只是 `/` 和模型相关能力不可用。
- 禁止触碰、必须遵循只锁 AI，不锁人。
- 人搜得到禁止触碰的笔记。模型的本地检索搜不到。
- MCP 读到的、带出的，走同一套门。联网开关同样约束 MCP。
- 一场 `/` 只改当前打开这篇的正文和本篇附件。
- 切到另一个笔记 tab，这场立刻散场。
- AI 新建一篇后，人不被拽走。这场继续。新笔记在库里，要看自己点开。
- 半成品技能能存，不能加载。名字、什么时候用、具体怎么做都写齐了才能加载。
- 库就是磁盘上那个文件夹。备份靠人自己。软件不另做快照，也不把库绑成 git。

## 2. 产品合同

已点头。不做就会做成别的软件。

### 壳与运行时

- 壳是 Electron。v0 就要 Mac 与 Windows。
- 产品逻辑纯 TypeScript。不上 Python 边车。探路用的 Python 已移除，产品骨架是 Electron + TypeScript。
- 主进程 `AgentHost` + [Vercel AI SDK](https://ai-sdk.dev/) + 官方 MCP TypeScript 客户端。
- Harness 做实：目标 → 工具 → 观察、硬刹车、错误回喂、完成可核对。
- 外循环以后再说。v0 不无人值守扫库。
- 无 Shell。

### 编辑与渲染

- CodeMirror 6 即时渲染。文档是 Markdown 字符串。
- 正文只有一条编译管线。语法用插件加。画布不另解析一套。写盘写编辑器里的 Markdown 字符串，不用 AST 倒回去冒充原文。
- 公式、图、表、wikilink、callout、嵌入做成 viewport widget，懒加载。
- v0 渲染范围：GFM + frontmatter + 公式 + callout + `[[链接]]` + 嵌入 + Mermaid。
- Callout 跟 Obsidian 常见写法走（`> [!note]` 这类）。
- 嵌入：v0 只做可点的 `[[全路径]]`，不把另一篇正文嵌进当前篇。图仍可插在文中。嵌笔记以后再说。
- `[[链接]]`：括号内写完整路径，避免重名。界面只显示文件名。例如磁盘是 `[[工作/会议纪要]]`，屏幕上是「会议纪要」。
- 用 5～10 篇含公式、图、表、双向链接的长文压滚动与输入延迟。测得的数字补进本节。
- 不为别的编辑器做兼容。
- v0 不做「一键纯源码」。

### 记录即正文

- 正文是成品稿。
- 段是块。只能拖到段落之间。拖动是搬家。
- 屏幕上两种样子：你写的，和还没采纳的 AI 块。采纳后跟手写一样。
- 每段有稳定编号。拖动只改当前顺序，不改编号。
- 点「采纳」才转正。拖只换位置，不换身份。
- 默认按段落切成多块。可以多选，一起拖、一起采纳。
- 未采纳的 AI 块不能改字。先采纳再改，或删掉再问。账本里的原文不动。
- 你的口令不是 AI 块。
- 一段有三种身份：人写的、未采纳的 AI 块、口令。身份要跨会话存活（散场后未采纳块仍留在这篇里），所以它必须能从文件本身读出来。落到文件里的只有身份标记，具体写法随 `/` 一起定。
- 块编号不落盘。编号与顺序在每次打开时重新派生；「拖动只改当前顺序，不改编号」只在这一次打开、这一场 `/` 里成立。

### 一场 `/`

- 只从空段的段首按 `/`，就在这一段打字。选中一句或一段不会开对话。要对着它们说话，另找空段按 `/`，用话指出来。
- 回车发送并散场。Shift+回车换行。
- 这段变成带轻标记的口令。AI 块接在下面。
- AI 先出现在你按 `/` 的那段下面。位置不对就拖。模型不负责选落点。
- 一场就是你一句、AI 一段。下一句是账本新的一章。新回答落在你新按的那个 `/` 下面。
- 点结束或关掉输入条、点到正文别处开始自己写、回车发出这一句、切 tab，都散场。
- 没有「继续问」自动咬住上一块。还要聊就再自己找段首按 `/`。
- 未采纳的 AI 块留在散场时那篇里。
- 生成中途可用按钮或 Esc 停。已写出的段落留下，仍是未采纳 AI 块。账本记「已中止」和当时那些字。

### 账本

- 只读。按次按日期分场。
- 写在这篇笔记同一个文件里。文件树里不出现，不能当一篇笔记点开改。正文画布里也没有编辑位。
- 入口在当前笔记标题旁边。点开临时 tab 只读回顾，关掉就走，不占右侧反链。
- 你对 AI 说的话会留在正文里（你的样式，能改能删，有很轻的标记）。若注入了技能，口令上还要明显标出技能名。
- 账本另存一份不能改的，并记技能名。删正文口令不会擦账本。
- 每一章记：口令、AI 当时全文、一句很短的工具摘要。
- 不记思维链。不记事后会过期的位置地图。
- 内部思维链不进笔记。跑时可展开看，任务结束丢掉。不另做缓存库。
- 账本写在同一文件的最末尾，用一行机器锚点 `<!-- rgent:ledger:v1 -->` 与正文分开。正文永远在锚点之前；锚点之后只属于账本。
- 正文在前，编译出的位置因此不需要位移；纯文本编辑器与 git diff 看到的是「你的文章 + 一段追记」。
- 索引一律只吃锚点之前的正文：人搜、反链，以及将来的模型检索与喂给模型都不得看见账本。
- 锚点行是选定值，不是永久合同（带 `v1` 以便日后能检测而不是误读）。库里目前没有任何账本，改锚点等于一处常量加一次扫描迁移。

### 喂给模型

- 每次都带两份并贴标签：正文（尽量全文；块编号 + 当前顺序 + 身份）和账本。
- 另带这一次 `/` 点在哪两块之间。
- 只有超过该模型上限才截断正文。
- 相邻两段不等于相邻两轮对话。
- 口令在正文和账本里都会出现。稿是什么听正文。

### 库、文件、窗口

- 文件夹里已有的 Markdown 都是笔记。其它文件能在树里看见，但不按笔记打开。
- 每篇笔记自己带一个附件小文件夹，名字就是笔记名（`工作/会议纪要.md` 配 `工作/会议纪要/`）。图和 PDF 放这只夹里；插入附件时才建夹，不给空笔记预先建空夹。
- 引用写全路径：`![](会议纪要/pic.png)`、`![[工作/会议纪要/pic.png]]`。解析仍按 Markdown 标准相对路径走，软件不额外去同名夹里猜——这样同一份文件在别的编辑器里也显示得对。
- 文件名跟标题走。「会议纪要」就是 `会议纪要.md`，附件夹同名。不能当文件名的符号由软件替换。改标题就改文件名，附件夹一起改，库内 `[[全路径]]` 也尽量一起改掉。
- 平时自动写盘，也可随时手动保存立刻再写一次。不是纯手动。
- 窗口里的稿和磁盘上这份文件不一样了，问你听谁的，不默默盖掉。
- 可以开多个笔记 tab。正在看的那篇才是「当前这篇」。
- v0 不拆成两个窗。写字边界跟着当前 tab。
- 左边文件夹树可收起，默认收着。右边反链常驻。要翻目录再拉出左边。
- v0 要有反链。打开一篇能看到谁链到了它，按文件夹分组，点文件名跳转。呈现要组织得好看，不糙。
- v0 不做应用内历史版本。

### 权限

- 三档：必须遵循、禁止触碰、可参考。未标明的路径默认可参考。
- 必须遵循只锁 AI：人能改这些笔记；模型不能写，`/` 只提示只读。
- 禁止触碰只挡 AI：人能打开、能搜到；不进模型检索，`/` 碰不到。
- 一份路径名单。设置界面改，真正写在库里隐藏文件。换机器、进 Git 跟着库走。
- 文件树里对文件夹右键设档。设置页有一张总表。
- 树上只给「禁止」和「必须遵循」打标。默认可参考不挂徽章。
- 权限名单模型不能改。规则文件 AI 不可写。

### 检索与联网

- 不靠人在哪个文件夹里机械分类。专业问题由模型判断是否先搜本地、不够再上网。
- 「必须按原文」在提示里写死：涉及就查，回答要对着原文。
- 写盘仍不听模型：禁区碰不到，必须遵循的原文不能改。软件可抽查是否真的检索、引用。
- 人：v0 就能搜标题，也能搜正文句子。人搜得到禁止触碰。
- 模型检索不含禁止触碰。两套可见范围，不要做成同一份「看不见」的索引。
- 专业问题默认可把相关片段带去网上搜。有应用级联网总闸：开则可搜网、抓页；关了只查本地库。
- 禁止触碰的内容永不带出，MCP 也不例外。必须遵循的原文尽量只带问题或少量摘录。
- 联网总闸独立于设置主入口。
- 人搜用库里那份全量索引（含禁止触碰）。将来模型检索是同一份全量语料上的另一套可见范围：允许查询期过滤，禁止建索引时把禁区从人的那份里抹掉，做成唯一一份「看不见」的索引。

### 模型

- v0 就能换厂家，也能填兼容 OpenAI 的接口地址。
- 预置 DeepSeek 和 MiniMax。
- 密钥只进系统密码库，不进笔记文件夹。
- 本机模型（Ollama 等）不进 v0。
- 不配密钥也能用笔记。配了才有 `/`。

### 技能

- 技能是 prompt 说明文。不是文件树里的文档，也不是 MCP。
- 人只能在设置里技能这一页打开编辑。
- 磁盘上跟库走，对文件树隐藏。文件树里没有技能文件。
- 做好不等于能用。必须有加载、卸载。只有人点加载、卸载。没写完也能先存着。名字、什么时候用、具体怎么做都写齐了才能加载。
- 没加载的只待在技能库，不进 `/` 候选栏。卸载后文件还在。模型不能自己上架。
- 生成技能两条路：
  1. 设置里点「制作技能」，按内置模板手写，产出未加载技能文件。
  2. 在可写笔记里用 `/` 把需求谈清楚，浮栏里用内置「生成技能」。先确认会新建一份未加载技能、这篇笔记不删不收走。点头后另外新建一份完全按内置模板填好的技能文件，未加载、树上看不见。原笔记原样留着，文件树不动。
- 新建后立刻打开设置里技能这一页这份未加载技能，由人检查再决定加不加载。
- 制作过程留在原来那篇笔记里，不进技能。
- 技能按软件内置模板把事说清楚。人不改这份模板。就地收走、删笔记、账本进技能包均作废。
- 禁止触碰的笔记不能拿来生成（正文不送模型）。必须遵循里 v0 的 `/` 仍只提示去可写笔记，不在这篇里生成。
- 「生成技能」是内置动作，不是某个已加载技能。
- 技能只在设置的技能页里删。卸载只是不用，删除才从库里拿走。
- 一按 `/` 立刻浮出已加载技能的全量可滚动候选栏。一次只能绑一个。打字或空格即放弃注入。
- 口令上必须明显标出技能名。

### 工具

- v0 内置读库、写稿、检索、按开关联网。
- 设置里可以接 MCP。不接也能用。
- 技能是说明文，MCP 是手。两套不能混成一种。模型不能自己接上 MCP。
- 一场 `/` 里：只能改当前打开这篇的正文和本篇附件；可以新建笔记、改名、挪文件夹；删必须人在弹窗点头。
- 要改另一篇的字，得先打开那篇再 `/`。
- 必须遵循不能改字。禁止触碰碰不到。不是后台扫库。
- 工具按建 / 补当前篇 / 改名 / 挪 / 删拆开。删要确认。

### 设置里有什么

- 一个设置界面，分组页面。通用、模型、权限、技能都是其中一页。技能不单独再做一个面板。
- 已点名会进设置的至少有：库路径、模型与密钥、权限总表、技能（制作、编辑、加载卸载、删除）、MCP 连接。

## 3. 明确未锁

下列不要写成已经定案：

- 主题
- 图谱
- 日记模板
- 编辑器内核包名
- 全文检索实现
- 设置面板像素
- 底栏具体摆法
- Windows / macOS 最低系统版本
- 安装包、签名、商店分发
- 第 2 节压测测得的延迟数字（测完再写入）

未锁项要落成围栏时，先改本文再施工。窗口零件怎么摆，实现时再问；不要把尚未进围栏的备忘写进本文。
