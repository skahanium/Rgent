## Agent 核心框架

编码 Agent 入口是仓库根目录 `AGENTS.md`，不是本节。本节是产品里一场 `/` 的运行时。

### 功能愿景

Agent 不是侧栏聊天，也不是通用驾驶舱。人在当前这篇空段段首按 `/`，模型在这一篇正文里工作：口令留在稿上，回答先变成未采纳块，点头才跟手写一样。没密钥时笔记照常，只是 `/` 不可用。

一场 `/` 就是你一句、它一段。回车关闭输入态并开始生成；Esc、切 tab、关窗或停止按钮取消生成；已写出的字留下，仍是未采纳，并记原因。

发挥模型：给它正文（尽量全文；超限则保文首和落点附近、中间砍）、账本、这次 `/` 夹在哪两块之间，让它自己选工具、自己排步骤。应用不另做规划器。应用只组上下文、执行过门的工具、硬刹车、让人能核对。

合同见 [已拍板决定](decisions.md) §一场 `/`、§喂给模型、§工具、§壳与运行时。

### 技术选型

| 层 | 用 | 不用 |
|----|----|------|
| 宿主 | 主进程自建 `AgentHost` | LangGraph / Mastra / 多 Agent |
| 模型环 | Vercel AI SDK `streamText` + `tools` | 各家原生 SDK 各写一套 |
| MCP | 官方 TypeScript 客户端，经 Host 代转 | 模型自己接；无法代转的服务器 |
| 到画布 | 现有 IPC | 渲染进程内嵌厂商 SDK |
| 密钥 | Electron `safeStorage` | 笔记库、仓库、明文占位 |

环：Host 组三样 → `streamText` 字进未采纳块 → 有工具时 Host 在主进程过门执行 → 观察回喂 → 取消或限额刹车。不走人的 `noteWrite`。库内容、网页与 MCP 返回值均是低信任数据，不能提升为指令。

AI SDK 尚未进 `package.json`。栈名已进围栏，版本开工那一刀再钉。

### 实现路线

无日期。

- 最小环和五件工具拆成两刀
- 最小环无搜库工具
- 默认硬上限见 [已拍板决定](decisions.md) §壳与运行时；超限和取消均停止后续工具，保留未采纳内容与原因

```text
门禁（tierFor）
  → 身份标记
  → Host 最小环：最小模型配置 + safeStorage 密钥存储 + streamText + 未采纳块 + 取消。无工具
  → 内置工具：读库、补当前篇、建、改名、挪、删；搜库（可引用片段，方法未锁）
  → 技能
  → MCP（仅代转）
  → 联网搜 / 抓页
```

## 数据安全

### 功能愿景

库是磁盘上的明文 Markdown，不当保险箱、不另做加密层。要防：渲染进程乱摸盘、密钥进库或进 git、媒体/符号链接逃出库根、页面乱跳，以及抓回来的网页冒充系统提示。模型不可信。

### 技术选型

| 要防 | 用 | 不用 |
|------|----|------|
| 渲染进程摸盘 | `sandbox` + `contextIsolation` + preload 白名单 | `nodeIntegration` |
| 乱开页 | 拒绝 `window.open`；`will-navigate` 拦下，http(s) 走系统浏览器 | 内嵌第二套浏览器 |
| 脚本 | CSP：`default-src 'self'`；图允许 `data:` 与 `rgent-vault:` | 随意 `unsafe-eval` |
| 媒体逃出库 | `resolveInVault` + `realpath` | 按词法路径直接读 |
| 密钥 | Electron `safeStorage` | `.env`、笔记文件夹、仓库 |
| 网页回灌 | 纯文本 / Markdown 摘录，当不可信 | HTML/当系统提示 |

壳加固已在代码里。强制点见 [架构](architecture.md)。

### 实现路线

Host 最小环同时接上 `safeStorage`，密文只存应用数据目录；发行前分别验证 macOS 签名后读取与 Windows DPAPI。抓页清洗跟联网那一刀。

## 数据隔离

### 功能愿景

门禁挡模型，不挡人。人能打开、能搜到禁止触碰。模型检索没有禁区，`/` 碰不到，代转也带不走。必须遵循人能改、模型不能写。一份全量语料，查询期过滤，不建「看不见」索引。

### 技术选型

| 问题 | 用 | 不用 |
|------|----|------|
| 名单 | 库根 `.rgent-permissions`（架构选定值） | 写进正文；走 `noteWrite` |
| 谁改 | 人：树右键（本阶段）/ 设置总表（以后）。主进程专用 IO | 模型工具 |
| 跟随 | 文件夹 → 子路径；笔记 → 同名附件夹。更长条目优先 | 建索引时抹禁区 |
| 执行点 | 人的读/搜不看档。进模型的出口都看 `tierFor` | 人搜也滤禁区 |

条目格式（JSON）只在 [施工图](build.md)，未进围栏。

### 实现路线

当前阶段把名单做成 `ready(entries)` / `invalid(error)` 与纯函数 `tierFor`。缺文件是空名单；已有文件损坏或不可读时保留原文件，人读写搜继续，未来 AI 出口全部拒绝。Host 每次组上下文和执行工具前重新读有效名单；不能只用启动时缓存。

## 多进程 / 并发

### 功能愿景

画布不能去碰盘、跑模型、建索引。打字、自动写盘、监听、退出 flush、以后流式写未采纳块，不能互相丢稿或卡死窗口。不多库并行，不把索引做成独立服务。

### 技术选型

| 问题 | 用 | 不用 |
|------|----|------|
| 进程 | v0 先把索引和 Host 放主进程，压测后可迁移 | Python 边车 |
| 通道 | `shared/ipc.ts` | 渲染进程自己开网、读盘 |
| 索引 | 惰性全量，查询时重建；打字不触发 | 按键增量（现在不需要） |
| 退出 | 先 flush，`will-quit` 才 `dispose` | `before-quit` 先拆库 |

主进程重建索引若使输入或取消响应不达标，应调整执行位置；当前布置不是产品性格。

### 实现路线

本阶段先修笔记同目录原子替换、内容修订值和同篇应用内串行写；外部修改冲突交给人选磁盘或窗口稿。流式回画布走现有 IPC；未来取消用 `AbortSignal` 覆盖 Esc、切 tab 与关窗。

## 手动检索

### 功能愿景

没密钥也能搜标题和正文句子。禁止触碰搜得到。账本搜不到。

### 技术选型

当前工程选型是惰性全量重建 + 标题与正文子串（大小写不敏感）。可按压测调整引擎；人的全量可见与只吃 `partition.body` 是合同。主进程搜，渲染进程只展示。最多 100 条、排序、片段规则未写成围栏数字。

向量检索是非目标。

### 实现路线

人搜已可跑。门禁落地后，人搜仍然不过滤禁区。不要在本阶段换引擎。

## AI 检索

### 功能愿景

模型和人查同一份语料，只是看不见禁止触碰。返回可引用片段，好兑现「必须按原文 / 可抽查」。不是向量检索。

### 技术选型

同一份 `VaultIndex`（只吃正文）。查询期 `tierFor`。**方法不与人搜子串绑定**；倒排 / BM25 / 按块切未锁。合同是「带路径的可引用片段」，不是「子串扫描」。

「软件可抽查是否真检索、引用」方法仍未锁。

### 实现路线

晚于门禁。Host 最小环不做搜库工具。工具那一刀再上搜库。实现可以先朴素，换引擎不改性格。

## 联网搜索与抓取

### 功能愿景

专业问题可以由模型决定：先查本地（门禁内），不够再上网。应用级总闸。禁区不经代转带出。抓回网页当不可信，进模型只准纯文本 / Markdown 摘录。不是第二套浏览器，不是模型自己 `fetch`。

### 技术选型

主进程 Host 内置工具，过总闸和 `tierFor`。搜索引擎、抽正文库、超时体积未锁。关闸时内置工具不发请求；不能代转的 MCP 不准处于已连接。

### 实现路线

最小环无工具，故无联网。本地工具之后、总闸 UI 和 `safeStorage` 之后再做。先锁出口和回灌形态，再选供应商。
