# 开源说明

本文只约定许可、贡献与治理怎么写清楚。仓库暂不提供 GitHub issue / PR 模板，也不提供 CI；这些以后若要做，再单独立项，不在本文假装已经存在。

施工纪律见 [施工守则](handbook.md)。围栏见 [已拍板决定](decisions.md)。

## 许可

Rgent 以 [MIT License](../LICENSE) 发布，与 `pyproject.toml` 中的 `license` 字段一致。

你可以在 MIT 条款下使用、复制、修改、合并、发布、再许可和出售本软件。软件按现状提供，不含任何担保。

## 谁在维护

目前为一人维护（见 `pyproject.toml` 作者：Skahanium，`skahanium@gmail.com`）。不承诺响应时限，不承诺路线图日期。

重大围栏以 [已拍板决定](decisions.md) 为准。维护者可以拒绝与围栏冲突的改动，并请先改文档再提实现。

## 如何贡献

1. 阅读 [文档地图](README.md)、[理念](vision.md) 和 [施工守则](handbook.md)。  
2. 改行为或架构前，说明要动的是哪一条围栏。  
3. 欢迎讨论、补文档、补测试与实现。当前没有强制的 PR 模板或自动化检查；仍请不要提交密钥、会话库、个人数据目录内容。  
4. 提交不要包含真实 API Key、凭据库导出、用户数据目录里的库文件，或把密钥写进示例代码。  

根目录 [CONTRIBUTING.md](../CONTRIBUTING.md) 指向这里。

## 安全披露

若发现可以导致密钥泄露、工作区外写入、或未过目即写盘的问题，请不要在公开讨论里贴可复现的利用细节与真实密钥。

请发邮件至 `skahanium@gmail.com`，说明影响范围与复现条件。不承诺修复时限，但会优先于普通功能讨论。

## 发布

版本号以 `pyproject.toml` 为准。安装包、签名、商店分发尚未纳入当前围栏。源码形式的发布（标签、打包到索引）若开始做，再补流程，不在此虚构流水线。

## 行为与范围

本项目是本机 Agent 客户端。贡献若把默认形态改成网页服务、云同步或多租户后端，与 [理念](vision.md) 的非目标冲突，应先作为围栏修订讨论，而不是直接合入。
