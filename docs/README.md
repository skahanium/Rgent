# 文档地图

从这里进入 Rgent 的文档。

**围栏篇**只写已经拍板的产品性格。未锁的实现不要装成已定方案。

**施工图**写当前做到哪、下一步碰哪。它不是合同：过期只改施工图，不改性格。

改产品性格或架构时，以 [已拍板决定](decisions.md) 为对照表。先改那一篇，再改其它围栏篇和代码。

编码 Agent 从仓库根目录 [AGENTS.md](../AGENTS.md) 进，不要从本文或 [理念](vision.md) 开写。

## 两栏

| 栏 | 文档 | 管什么 |
|----|------|--------|
| 围栏 | [理念与远期](vision.md) | 这是什么、要去哪、故意不做什么 |
| 围栏 | [已拍板决定](decisions.md) | 原则门、产品合同、明确未锁。数字和禁令只写在这里 |
| 围栏 | [架构](architecture.md) | 已拍板结构，以及这些结构在代码里的强制点 |
| 围栏 | [施工守则](handbook.md) | 动手纪律，避免把围栏做歪 |
| 围栏 | [开源说明](opensource.md) | MIT、贡献、治理、安全披露 |
| 施工 | [施工图](build.md) | 依赖顺序、只展开当前阶段 |
| 施工 | [施工对象](topics.md) | 工程题的愿景、选型、路线。不是合同 |

不设独立 ADR 目录。新的重大决定写进 `decisions.md`，必要时在对应围栏篇补一句。阶段里的实现取舍最多写三行「为什么现在这样」；点头后再升格。

其它篇用链接指向 [已拍板决定](decisions.md)，不要再抄一份数字和禁令。

仓库根目录的 [README](../README.md) 只做入口，不重复总账全文。许可见 [LICENSE](../LICENSE)。参与贡献见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 建议阅读顺序

人：

1. [理念与远期](vision.md)
2. [已拍板决定](decisions.md)
3. [架构](architecture.md)
4. [施工守则](handbook.md)
5. [开源说明](opensource.md)
6. 动手时看 [施工图](build.md) 的当前阶段
7. 工程题（Agent、检索、隔离等）看 [施工对象](topics.md)

编码 Agent：根目录 [AGENTS.md](../AGENTS.md) → [施工图](build.md) 当前阶段 → 需要时 [架构](architecture.md) 强制点 → 相关代码。合同冲突以 [已拍板决定](decisions.md) 为准。

## 用语

文档里这些词始终是同一个意思：

| 用语 | 意思 |
|------|------|
| 库 | 用户选的那个文件夹 |
| 正文 | 你看见的成品稿 |
| 账本 | 同文件里只读的讨论记录，树上没有 |
| 一场 `/` | 一次从段首斜杠开始的交互；回车开始生成，切 tab 或关窗取消 |
| 当前这篇 | 正在看的那个笔记 tab |
| 必须遵循 / 禁止触碰 / 可参考 | 三档权限，只挡 AI |
| 技能 | prompt 说明文，不是树上的笔记，也不是 MCP |
| v0 | 围栏内第一代可演示客户端 |
| 围栏 | 上表左栏那些篇。产品性格的唯一合同 |
| 施工图 | [build.md](build.md)。当前阶段与依赖顺序，不是合同 |
| 施工对象 | [topics.md](topics.md)。工程题的愿景 / 选型 / 路线，不是合同 |
| 当前阶段 | 施工图里标明正在做的那一格。未开的对象禁止实现 |
| 应用代转 | 主进程发出的网络与片段；能过门禁和联网总闸 |
| 进程级出口 | MCP 子进程自己开的 socket；应用拦不住 |
