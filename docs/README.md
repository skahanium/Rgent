# 文档地图

从这里进入 Rgent 的文档。

**围栏篇**只写已经拍板的产品性格。未锁的实现不要装成已定方案。

**施工图**写当前做到哪、下一步碰哪。它不是合同：过期只改施工图，不改性格。

从决定到交付按一条链读：**产品决定**在 [已拍板决定](decisions.md) → **未决工程问题**在 [施工对象](topics.md) → **阶段依赖与交接**在 [施工图](build.md#跨能力交接) → **代码与测试证据**在相应阶段记录 → **真实窗口、双平台与用户确认**分别核验。现行规则不与历史交付数字混写；[本轮对照表](build.md#本轮交付对照)按提交区分通过、失败及待核。未来合同不是当前施工许可。

工具、任务权限与第三方接入按同一条链读：[沙箱与单场授权合同](decisions.md#沙箱与单场任务授权合同与开放边界) → [工程职责、平台候选与两道开放门](topics.md#沙箱与任务授权) → [依赖、交接与讨论裁定](build.md#三项讨论后的规划调整) → [现有边界](architecture.md#沙箱边界的现状)。沙箱是跨能力基础设施；文件操作基础、一次性授权与两项只读工具已有实现，当前为库内记忆，删除／恢复核验独立未开，既有 renderer 隔离不代表 Agent 沙箱已经交付。

记忆协作升级先读[2026-10-08 局部合同](decisions.md#2026-10-08-记忆模型协作与实际任务收益局部授权)与[五包施工](build.md#2026-10-08-记忆模型协作与实际任务收益)；其后的支撑以[2026-10-09 局部合同](decisions.md#2026-10-09-记忆协作支撑局部授权)与[协作支撑施工](build.md#2026-10-09-记忆协作支撑)为准。源码比较见[唯一研究专题](memory.md)。

记忆的阅读路径：[已批准的库内记忆合同](decisions.md#库内记忆) → [材料、召回、整理与遗忘工程边界](topics.md#库内记忆工程边界) → [前置状态及施工包](build.md#库内记忆) → [v4／v5／v6 施工与实测结论](build.md#2026-10-05-v6-自动记忆实用化与验收重整) → [实际存储、来源与 Host 接线](architecture.md#记忆的存储与来源边界分包施工中) → 对应提交及验收证据。记忆是库内长期资料，设备开关与模型配置有独立边界；不是 `/` 中的逐条引用选择。当前状态：v6 r9 认证后普通应用整理已切共同管线，成绩按设备级只读文件如实显示；人工复核、Windows／双平台 CI／原生输入法／用户视觉仍待核，未达门模型不改写成通过。
技能按同一条链读：[技能局部授权](decisions.md#2026-10-12-技能局部授权)（含同日修订与三处澄清） → [前端协议·技能页](frontend.md#技能页2026-10-12-局部授权) → [施工图·技能](build.md#技能)（包 1–5 与真机取证结果） → [架构强制点](architecture.md)（技能只由人写、按场冻结）。

改产品性格或架构时，以 [已拍板决定](decisions.md) 为对照表。先改那一篇，再改其它围栏篇和代码。

编码 Agent 从仓库根目录 [AGENTS.md](../AGENTS.md) 进，不要从本文或 [理念](vision.md) 开写。

## 两栏

| 栏 | 文档 | 管什么 |
|----|------|--------|
| 围栏 | [理念与远期](vision.md) | 这是什么、要去哪、故意不做什么 |
| 围栏 | [已拍板决定](decisions.md) | 原则门、产品合同、明确未锁；产品级数字和禁令写在这里 |
| 围栏 | [前端协议](frontend.md) | 已确认的视觉语言、界面结构和呈现规则；静态图只作观感参考 |
| 围栏 | [架构](architecture.md) | 已拍板结构，以及这些结构在代码里的强制点 |
| 围栏 | [施工守则](handbook.md) | 动手纪律，避免把围栏做歪 |
| 围栏 | [开源说明](opensource.md) | MIT、贡献、治理、安全披露 |
| 施工 | [施工图](build.md) | 依赖顺序、只展开当前阶段 |
| 施工 | [施工对象](topics.md) | 工程题的愿景、选型、路线。不是合同 |

不设独立 ADR 目录。新的重大产品决定写进 `decisions.md`，前端呈现细则在 [前端协议](frontend.md) 展开，不重复产品行为。阶段里的实现取舍最多写三行「为什么现在这样」；点头后再升格。

其它篇用链接指向 [已拍板决定](decisions.md)，不要再抄产品级数字和禁令；可调整的阶段工程默认值见 [施工对象](topics.md#agent-核心框架)。

仓库根目录的 [README](../README.md) 只做入口，不重复总账全文。许可见 [LICENSE](../LICENSE)。参与贡献见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 用语

文档里这些词始终是同一个意思：

| 用语 | 意思 |
|------|------|
| 库 | 用户选的那个文件夹 |
| 正文 | 笔记画布对应的文件内容，包含你写的笔记、提交后的提问和未采纳的 AI 回答；账本不属于正文 |
| 账本 | 主进程独立服务保存的同篇结构化任务历史，供应用内只读回顾，树上没有；旧同文件尾部只供保真迁移 |
| 一场 `/` | 从段首斜杠开始的输入交互；回车准备授权、再次确认发送；切 tab 结束输入交互 |
| 生成任务 | 提交后绑定发起时的笔记；散场不自动取消，切 tab 后仍向原笔记产出；Esc、停止或关窗可取消 |
| 当前这篇 | 正在看的那个笔记 tab |
| 必须遵循 / 禁止触碰 / 可参考 | 三档权限，只挡 AI |
| 单场任务范围 | 默认只读发起篇正文与本篇账本；人另授读取、新建及跨篇结构范围，均与库权限取交集。范围授权不隐含向搜索／MCP 发送或扩大正文写入权，详情见 [合同](decisions.md#沙箱与单场任务授权合同与开放边界) |
| 发送批准 | 核对选定模型接收方；受本地上下文影响的外部请求另确认内容、目的地和用途，派生文本同样受控。模型接收方确认已接入，其他未来外部发送接口未开 |
| 沙箱体系 | 应用授权与执行隔离共同约束任务及第三方资源访问；当前只有部分基础边界，完整接线未开 |
| 技能 | 设备级技能条目（`body` 是交给模型的说明文），按库启用、按场冻结；不是树上的笔记，也不是 MCP |
| v0 | 围栏内第一代可演示客户端 |
| 围栏 | 上表左栏那些篇。产品性格的唯一合同 |
| 前端协议 | [frontend.md](frontend.md)。已确认的视觉与呈现规则；不开放未到阶段的施工 |
| 施工图 | [build.md](build.md)。当前阶段与依赖顺序，不是合同 |
| 施工对象 | [topics.md](topics.md)。工程题的愿景 / 选型 / 路线，不是合同 |
| 当前阶段 | 施工图里标明正在做的那一格。未开的对象禁止实现 |
| 应用代转 | 受信任服务转发经用途、来源、目标、有效权限和发送批准核验的数据；Agent 联网另过总闸，模型文本和图片分别授权 |
| 进程级出口 | 组件自身的文件、网络及子进程访问；未来须由 OS 隔离约束，无法证明双平台受控的 MCP 不接入 |
