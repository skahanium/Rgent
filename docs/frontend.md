手动重试和原生恢复事件在查询当前库之前立即取得交互保护，查询绑定原会话、独立读取代际及当前恢复 id。查询 10 秒超时保留草稿并给出再试诊断；只有当前查询可以交给完整恢复或释放自己的查询保护，原生交接门仍由主进程确认。新恢复 id／准备操作／会话淘汰旧成功、失败与清理回调；同一恢复操作随后发出的普通忙态及重复关闭更新保留当前查询。同会话重试不重放提交标记清空草稿。

本包 DOM 定向结果不代称构建窗口验证。实际窗口的恢复预览、取消、暂停离库、重开续跑与坏登记正文可读仍待整轮统一验证，证据状态见施工表；用户视觉和 Windows 仍待核。

## 设计语言

Rgent 是以写作和查阅为中心的工作区。画布安静，导航清楚，控件精致而可辨；科技感来自准确的层级、状态反馈与流畅操作，不靠霓虹、重阴影或成片装饰。参考 HanaAgent 等作品的整体协调感，但不照搬其布局、插画、品牌或主题名称。

- **日间：** 冷白画布、浅灰层次、同为浅色的侧栏；蓝紫色作优雅而克制的交互点缀。普通正文呈中性黑，不用绿色或蓝紫色染普通段落。
- **夜间：** 深蓝灰的“夜间档案”方向。画布、侧栏、浮层、文字、边界和点缀一起调整，保证久读舒适；不是把日间颜色逐项反相。
- **辨识符：** 当前落点使用短而清楚的“页边索引”细线，在树的当前项、编辑区位置提示、设置选中项等需要定位的地方沿用同一逻辑。它是状态标识，不铺满所有行。
- **字体：** 默认长篇正文用适合阅读的衬线字体、Markdown 标题用无衬线字体；用户可在设置中分别为正文和标题选精选的衬线或无衬线方案，两者可交叉搭配。导航、tab、控件和状态文字始终使用界面字体，不随阅读偏好改变。字重、字宽、行距需分别照顾中英文和长文。
- **形状与层级：** tab 和小控件保留柔和圆角；画布、侧栏与浮层靠轻微明度差、细边界和节制阴影分层。圆角和悬浮不应把笔记正文切成一组卡片。
- **控件细节：** 使用已选定的“清晰轮廓”方向。同类图标使用一致的尺寸、线重与对齐网格。图标本身可以小，实际可点区域须足够清楚；默认、悬停、按下、选中、聚焦和禁用状态采用同一套反馈逻辑，不让用户猜控件能否操作。
- **动效：** 采用已选定的“轻快克制”节奏，用短促、稳定的颜色、透明度或小幅位置变化表示状态；输入、滚动、切 tab 时不跳动布局，内容切换不等一段退场动画才响应。不做持续闪烁或大面积光效。系统要求减少动态效果时停止非必要过渡。

### 语义 token

实现时先以语义角色组织日夜两套值，再为组件引用角色，不在各处散写同一色值。最低限度应区分：`surface.canvas/nav/overlay`、`text.body/heading/muted/onAccent`、`accent.primary/soft`、`focus.neutral`、`border.subtle/strong`、`state.hover/selected/disabled`、`ai.prompt/answer`、`status.online/offline/error`，以及字体、间距、圆角、阴影和动效时长的相应角色。提问比回答有更强的视觉权重，回答使用更柔和的同系伴随色；日间可表现为深浅差，夜间按对比度调整，不机械压暗提问。两者与普通正文一眼可辨，同时仍像文章内容。联网状态的蓝色光晕是状态色，不强迫所有交互都变蓝。

这些**角色和相互关系已定**；具体 hex、字体文件、宽度、间距、圆角和毫秒数在实现与双主题检验中调整。装饰性分隔线可用 `border.subtle`，需要靠轮廓辨认的输入框和按钮用满足对比度要求的 `border.strong`。调整必须保持阅读层级、辨识度和可访问性，不得把数值临时稿提升成永久产品数字。

全客户端的按钮、卡片、选项、输入框、菜单和分隔柄在默认、悬停、按下、选中、聚焦等任何状态下，禁止紫色包围边框、outline 或环形 box-shadow；统一中性焦点 token，点击采用背景加深／填充变化。不得以移除紫圈为由隐藏键盘焦点；焦点须满足下文对比度。单侧选中标识、文字图标及任务状态可沿用强调色。

## 工作区

### 顶栏与侧栏

- 顶栏是多篇笔记的 tab 栏，沿用柔和圆角、当前项浅点缀底色、其他项安静退后的形式；文件图标与标题帮助辨认当前篇。tab 文字与原生窗口控制件在视觉上垂直居中。不得用单个文档路径替换 tab，也不在顶栏放 `rgent` 文字标识或账本入口。
- 单个 tab 常态及最大宽度为 `176px`（较此前缩减 20%）；篇数增加时先收缩标题并省略，保留图标、未保存标识及关闭按钮空间，最小宽度为 `112px`。继续增加时只在 tab 栏内部横向滚动，不越过顶栏或原生控制区。新建按钮紧随最后一个 tab，与 tab 一起排列和滚动；打开末尾笔记时一并露出加号。打开、切换及窗口缩小时让当前项可见，编辑与保存重绘保留手动滚动位置。
- 侧栏目录、文档及附件等资源名称使用 `calc(0.86rem - 1px)`，较此前缩小一号；附件归属说明维持辅助文字层级。
- 左侧栏日间保持浅色。它仍可收起且默认收起，打开时不要挤坏正文和右侧反链。上方只列普通目录树，下方列选中目录的直接资源，路径行内的眼睛图标控制附件显隐，不显示文字、不单独占行；同名附件夹及其子树不上目录树。文件夹、Markdown、PDF、图片和其它资源须有可辨的类型图标，资源图标不代表内容打开能力。目录**平时显示文件夹图标**，鼠标悬停或键盘聚焦时，同一图标位置变为展开／折叠按钮，不在旁边额外添一枚箭头；图标位置始终是可点击的折叠目标，无悬停设备可直接点它，行的目录选择与图标的展开／折叠可分别操作。
- 侧栏宽度范围为 `192–360px`；默认 `224px`，内容窗口宽度 `≤820px` 时默认 `208px`。保护同窗、同阅读偏好、默认展开宽度下的正文行宽：先缩两侧留白至每侧最低 `24px`，再限制侧栏动态上限；`1200px` 内容窗约 `320px`、`800px` 约 `256px`。临时限制不覆盖首选宽度，窗口空间恢复时自动恢复。
- 侧栏右边设置 `8px` 覆盖命中区，不额外占布局；使用 pointer capture 拖动，松开才保存，Esc 取消，丢失捕获安全结束。宽度柄是可聚焦的垂直 separator，报告当前值及有效上下限；左右键每次 `8px`，Shift 每次 `32px`，Home／End 到有效最小／最大值，双击恢复当前窗口默认宽度。操作保持编辑器选区。
- 收起时用 `display: none` 完整隐藏侧栏、边框与分隔柄，不留 `48px` 空壳。焦点在栏内时先返回顶部展开按钮；重新展开保留目录、附件浏览、上下比例及会话滚动。
- 目录区与资源区默认占可用高度的 40%／60%，各自滚动；中间分隔条有可辨且足够的命中区域，支持拖动、键盘聚焦和键盘调节，并报告当前比例。调节不挤掉搜索入口；日夜和 `800×560` 窗口内两区仍可操作。
- 资源区有明确的当前位置和「显示附件」开关，默认隐藏同名附件夹；显示时在附件夹行标明「附件」与所属笔记。进入附件夹或子目录只更新资源区，保留上方目录树；返回控件能回上一级或所属普通目录，附件归属始终可辨。附件浏览隐藏资源区「新建笔记」，附件夹不提供独立改名／移动；其中 Markdown 沿用既有打开及安全操作，不扩展非 Markdown 打开能力。
- 选中目录与下方浏览位置保持独立于 tab：切 tab、搜索和反链打开不自动跳目录；不设「定位当前笔记」按钮。新建文件夹使用文件夹加号图标，与目录区标题同行，不显示按钮文字，保留悬停提示和可访问名称，始终针对选中普通目录；新建笔记在普通目录资源区；顶栏 `+` 针对侧栏选中普通目录，收起／附件浏览不改变目标，失效要求重新选择，右键入口针对右键目录；人的既有改名与移动菜单沿用原预览和门禁。
- 浏览偏好按设备、按库保存选中普通目录、展开状态、分区比例、附件开关、资源位置与可选首选宽度；旧记录兼容，损坏宽度字段只回退该字段，不丢其它有效偏好，不新增 IPC 或写入笔记库。滚动仅在会话内保留。恢复无效位置时回到仍存在的普通祖先目录或库根，并给出清楚的当前位置；显示偏好不改变权限或打开内容。行为与开放范围见[侧栏合同](decisions.md#侧栏目录与资源)。
- 设置入口固定在**底栏最左侧**：只有图标（比正文图标略大）、没有文字，命中区域不低于 28×28，可键盘聚焦并用无障碍名称说明它是「设置」；不随文件树或画布滚动。
- `搜索笔记`是保留现有圆角轮廓的按钮，文字旁显示平台快捷键，不放放大镜符号。⌘K／Ctrl+K 打开带搜索框与结果的悬浮页；⌘F／Ctrl+F 留给当前笔记的篇内查找。结果内容与人的全量可见范围按 [检索合同](decisions.md#检索与联网)，不由视觉稿决定排序或片段算法。

### 编辑画布与辅助信息

- 画布保持宽裕留白和清楚的文字宽度。宽窗正文适度拓宽，普通段落在阅读与编辑时一致地两端对齐，末行自然结束；标题、代码、表格和结构性列表保持各自的排版。普通正文承担阅读主角；工具、元信息和操作控件保持次要层级。日间普通正文为中性黑，夜间为舒适的浅色。
- 当前笔记的账本入口始终显示在正文画布右上角，滚动时不消失。账本在同一 tab 内临时只读显示；关闭后恢复正文的光标与滚动位置，不改草稿或文件内容。
- 提交后的 AI 提问留在正文，视觉上以较粗字重和前缀 `>` 标识，**不显示触发时的 `/`**。`>` 是由口令身份产生的显示前缀，不能为了画出它而把口令改写成 Markdown 引用；落盘内容和身份仍按 [记录即正文](decisions.md#记录即正文) 的规则。AI 回答向内缩进一个字宽。两者的颜色跟随主题，以不同强度的同系点缀作轻微区分；不使用独立底色卡片、粗边框或固定绿色。回答的“采纳”“丢弃”直接可见，其他操作收进“更多”，控件不压过文字。
- 编辑器／阅读器的右缘有悬浮标题索引，只取正文的一级、二级、三级标题。短线组位于画布可视区纵向中段；通常逐条显示紧凑的短横线，右对齐，一级最长、三级最短，不用一整块背景包住全组。可见短线的间距以早期过疏稿的**约 40%**为基准，命中区可以比短线大，不能因视觉紧凑而难以操作。悬停或键盘聚焦仅显示对应标题，激活后跳到对应标题；当前阅读位置有清楚的状态。索引属于画布边缘，不取代右侧反链栏。
- 独占源码行的图片按自身尺寸呈现，上限为正文宽度；图片位于行首而后面紧接正文或 Markdown 标题时，阅读态也把图片、正文或标题分开呈现，标题进入正常层级和页边索引，笔记原文不因此改写。句中的行内图片仍保持小尺寸，不把相邻文字挤到旁边。外链图片加载失败时显示简洁的说明与重试，不在阅读画面铺开长 URL；人的／已采纳正文 HTTPS 自动加载，未采纳 AI 正文、全部账本与 HTTP 图片逐张点击加载。点击前可查看地址和来源，详见 [编辑与渲染合同](decisions.md#编辑与渲染)。
- 右侧反链仍常驻，并按文件夹组织。底栏与上方用一条细线分开、**高度比正文行距略宽**：最左是设置图标入口，其后是行列与字数，**中间是模型模块**（原生下拉，按供应商分组，只列**已存密钥**的供应商及其模型，未配置或缺密钥的不出现；切换只为当前篇临时选择下一场模型，不改设备默认；启动成功复位、取消准备及启动失败保留，失效不静默回退；无可用模型时显示「未配置模型」与打开设置的引导，不放死控件），右侧联网圆点与只读库名；库名不可点击或键盘聚焦。底栏与客户端其它控件一律使用中性焦点描边／背景变化，禁止紫色包围线。已提交的生成任务运行时，单任务显示**来源笔记、任务状态与停止入口**；多任务显示数量，并能从小浮层逐项查看和停止。切到别的 tab 后仍指明原笔记，且不挤掉既有项目。联网总闸是一个可点击、可键盘操作的小圆点：离线灰色，联网时蓝色光晕；不常驻“联网／离线”文字，状态通过悬停提示和无障碍名称说明。Agent 联网功能未开放时只如实显示离线状态。

### 浮层与特殊状态

- 本轮仅新增 `/` 口令旁授权浮层：用现有主题、控件和焦点语言呈现发起篇、参考范围、实际接收的模型与主机及发送说明（模型选择在底栏，浮层只如实显示本场实际接收方）；回车确认，Shift＋回车换行，输入法组合不提交。预览变动重新确认，取消保留口令，不占用冲突决策浮层。工具运行状态与来源回顾复用既有底栏和同篇账本：显示模型步骤、读库／搜库及停止入口，账本区分实际读取来源与模型消息引用来源，并按发生顺序呈现过程（模型步、工具调用与结果、检索词、失败与收尾）；新模型推理由设备短期区核验任务后只读呈现，旧推理保留在迁移历史中；正文只出现回答，工具原文与思维链都不进正文；不重开整体视觉。写入失败的生成内容留作待保存：底栏提示写明原因与下一步，人在该篇修好语法并成功保存后自动补存一次；仍未落盘时关窗流程仍提供明确放弃。

- 设置主页及各级子页使用同一套字体、色彩、选中态、边界和控件语言。设置面板**悬浮在正常工作区上方，面积比正常面板小**，但有足够空间容纳真实样张；在最小窗口内留外边距并在面板内部滚动。打开时正文、侧栏和反链明显柔焦并适度压暗，面板保持清晰。面板没有独立顶栏、横向顶栏分隔线或右上角关闭按钮；“设置”是侧栏标题，点击面板外或按 Esc 关闭，面板内点击不关闭。导航按工作对象分组，可用页面配同风格细线图标；未开放页面不出现。将来的助手、记忆、供应商管理等导航，只随各自数据边界和可用能力开放，名称、控件与排布须届时核对，不从参考截图提前锁定。能力范围见 [产品合同](decisions.md#设置里有什么)。
- 已开放「界面」页的日间／夜间／跟随系统三选项；主题卡展示能辨认侧栏、标题和正文的微缩工作区，并在下面提供更大的中英文静态笔记样张。「界面」页另提供正文和标题的独立字体选择、正文字号、行距和最大阅读宽度；调节只即时更新面板样张，确认保存后才影响编辑阅读区、AI 正文与同篇只读账本，关闭未保存的调节则放弃。默认保持此前的衬线正文、无衬线标题和现有尺寸。「界面文字」另设 tab 名称及侧栏目录／资源两项小／默认／大档位；默认保持当前字号，小减 1px 且最低 12px，大加 1px。样张含长名称、目录、笔记和附件；只预览样张，保存才应用，取消／失败不动工作区。行高图标与省略同步适配，不改正文或根字号，tab 176px／112px及侧栏正文保护规则保持。助手、模型、运行页沿用同一面板语言，不显示不能使用的其他子页。助手页是设备级单助手的习惯：称呼（可空，≤ 40 字）、语气三选（平实／简洁／详尽）、补充说明（允许正常多行，≤ 500 字，带字数提示），加「保存」与「恢复默认」；保存前不生效，恢复默认只改草稿、仍需保存。助手页另有独立默认模型区域，按供应商列已配置模型，保存与习惯分离，默认缺失／失效提示处理，不自动替换。页面写明「所有笔记库共用、不改变笔记权限与工具范围」，并说明多助手、记忆与技能不在此页。模型页用两级子页：根页列出全部供应商（每行两行信息：供应商名与「密钥已保存／未保存 · N 个模型」，下面是端点主机），点一行进入该供应商的子页；子页顶部有返回根页的入口，内容依次是接口地址、密钥、模型清单（新增／移除／就地改上下文容量）与「读取模型」（页内展开候选，不占悬浮层）。一个供应商只有一份配置，界面不提供「再添加一条同厂商连接」。模型页不设「当前模型」按钮；助手页独立保存设备默认，底栏临时选择本篇下一场。空态与错误都在同一页内写明下一步。接口地址是唯一真源，已知端点只作该字段的候选（同一控件对所有供应商生效，不为单一厂商加控件）；密钥只显示保存状态，绝不回显。「读取模型」由人点击后只对当前连接发一次只读请求，结果只作候选、勾选后才写入，端点未提供上下文容量时要求人填并写明原因。运行页编辑三档有限上限。偏好按设备保存；跟随系统时响应系统变化。主题切换须同时作用于画布、侧栏、反链、浮层和原生窗口外观。
- 搜索是独立于侧栏目录与资源区的悬浮页。弹出后聚焦输入框，Esc 可关闭；键盘能访问结果并返回原工作区，打开结果不自动改变侧栏浏览位置。空查询内容、排序和结果片段不从静态图推导，沿用既有检索合同并在界面施工时核对。
- 窗口稿与磁盘稿冲突时，决策界面同时给出**并排的两份可阅读预览**：显示相同的前后文，分别强调发生变化的文字；“听窗口”“听磁盘”放在对应预览下方，并写明各自会舍弃哪份修改。不能只靠颜色表达差异。退出保存失败的重试、继续编辑、明确放弃，以及选库、库丢失和错误状态，也沿用这套视觉语言，操作结果以产品合同为准。
- 未来任务授权与扩展预览沿用现有浮层语言，分别让人辨认读取范围及选定模型接收方、结构动作的对象／目标／附件／影响，以及外部请求的实际内容／目的地／用途；读取不隐含向搜索或 MCP 发送。范围内连续执行仍提示失败或陈旧状态，删除另逐次确认。本轮已交付 `/` 口令旁授权浮层与工具状态／来源回顾；扩展授权与结构、外发用途预览的控件、入口和布局仍待各自阶段核对，设置页不新增，也不提供解除限制的开关；行为见 [沙箱合同](decisions.md#沙箱与单场任务授权合同与开放边界)。

## 可访问性与验收

- 中文输入验收必须走组合输入过程：预编辑逐字更新、退格、选词、连续输入、取消与撤销重做，不能只粘贴最终汉字。选词回车与候选 Esc 优先交给输入法，不准备／发送 `/` 或停止 Host；同时检查事件组合标志、IME 键码和编辑器组合状态。普通段落、标题、列表及 AI 块下方的人写落点都须保持完整文本、光标与既有原文换行；需要断段时在建立预编辑范围之前准备，取消不得留下自动空行，切篇后的迟到清理不得改动新篇。
- 日夜主题都按 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/) 检查：普通文本至少 4.5:1，大字至少 3:1；有意义的控件边界、图标和焦点指示至少 3:1。浅灰辅助文字与细线不能因“轻”而失去可读性。
- 选中、禁用、错误、权限和联网等状态不能仅靠色相区分；键盘焦点可见，文件夹切换、tab、搜索、标题索引、设置与冲突决策均能用键盘完成。悬停才出现的操作需有聚焦及无悬停设备的等价入口。
- 悬浮搜索、设置和模态决策打开时，焦点进入浮层；关闭后回到合理的触发位置。模态决策期间键盘焦点不能落到底层工作区；放弃修改、删除等破坏性选项不能成为默认操作。
- 验收至少覆盖当前支持的最小窗口 `800×560`、常用窗口 `1200×800`，以及日夜、长文、多 tab、长文件名、搜索与设置浮层、冲突双预览、减少动态效果。现有右反链与正文不能因窗口变窄而无声消失；更窄窗口的新布局另行讨论。

## 库内记忆（2026-10-03 v2 合同与窗口接线）

### 2026-10-04 记忆页排布与易读文案（局部授权）

单页按「本库记忆 → 已记住的内容 → 模型设置 → 最近整理记录 → 高级维护」组织。状态卡含开关、已保存状态、数量、实际整理模型和可访问的刷新图标。模型设置未配置／失效时展开，否则折叠；整理记录和维护默认折叠。卡片内距 16px、区间距 20px、字段间距 12px，内容宽度至少 600px 时模型区域并排。开关与本库模型仍共同显式保存，设备默认另行保存；未保存草稿、展开、筛选和焦点不被刷新覆盖。

内容以两行摘要、类别与状态呈现，展开查看完整内容与来源，点击编辑才进入表单，取消撤回本次草稿。本页筛选为全部（默认）、可使用、需要处理；需要处理包括来源待检查、待确认、待复核、争议和等待空间。使用「长期约定／参考知识」「默认整理模型／跟随默认模型」等易读名称；模型用途与发送内容按需说明。整理记录不虚构日期或笔记标题，完整任务 ID 收入详情。

高级维护使用「不再从已有材料学习…」「清空本库记忆…」「重置本设备的记忆设置…」及对应具体确认动作。预览必须说明保留与移除的内容、影响范围及重学规则；不简化一次性预览的安全核验，不新增自动确认。中性焦点、背景点击反馈和明确危险样式沿用全局合同。此节只授权呈现、文案与编辑体验；当时五页导航、自动学习与遗忘合同、存储格式和 IPC 保持既有规则。受验日期／提交及平台待核项见施工图。

本节登记时的当前阶段是「库内记忆」（前置本机门已通过）；按[库内记忆合同](decisions.md#库内记忆)开放第五页「记忆」及必要交互，2026-10-04 追加库管理页、2026-10-12 追加技能页后，**当前导航顺序为「笔记库、界面、助手、记忆、技能、模型、运行」**（技能页见下节）。**阶段名称以[施工图当前阶段](build.md#当前阶段)为准，本节不重复声明**；记忆页及补充入口已有接线，整轮验收仍按施工图登记。**「第N页」指建成顺序、不是导航位次**（定义见[设置合同](decisions.md#设置里有什么)）；人工待核项继续按施工图单列。

- 现有任务授权浮层只读披露记忆使用状态和独立整理接收方；不增加配置、逐条选择或新的确认步骤。实际启动固定的角色须与披露一致，确认前或异步准备期间变化则原预览失效。
- 记忆页展示当前库开关、设备默认记忆模型及当前库模型覆盖，模型均从设置中的有效连接选择；新库关闭、新设备模型空，模型缺失或失效提示人处理，不静默替换。保存结果和错误可辨，独立于助手习惯与单场模型。
- 页面可查看记忆内容、可核对来源及有效／暂停／待确认状态，并提供编辑、层级调整、停用、恢复、删除及必要的冲突确认；恢复先核验并展示变化，人确认才生效。正文获准选区与新结构化账本的人写口令字段的补充「记住」沿用可编辑预览，失败不改原文。删除不展示已移除正文；不以隐藏正文副本充当遗忘证据。删除确认说明：无法证明无关的待整理重试材料会一并清除，原笔记和账本不变；相关回执显示材料已清理、不可重试。后台整理的运行、预算、失败、取消和撤销结果应可核对，不伪装成功。

- 整理结果按层显示发生了什么、影响与下一步：请求、输出、提议、提交与结果分别可辨；"部分提交"必须显式说明哪些内容已保存、哪些被拒及原因，不能显示"整理成功"却隐藏长期内容全被拒，也不把非容量拒绝折成同一句格式错误。
