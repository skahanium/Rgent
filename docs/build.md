## 依赖顺序

无日期。下面是施工路标，不是连续施工命令；分支与交接表才说明强制前置。

```text
笔记壳能启动
  → 管线与画布
  → 账本缝与人搜
  → 门禁
  → 身份标记（含账本只读回顾）
  → 界面改造（前端协议落地）
  → Host 最小环
  → 笔记库文件操作基础
  → 统一任务授权与资源代理
  → 库内 AI 工具
  → 助手与多连接
  → 账本与上下文基础
  → 库内记忆
  → 技能
  → 远端 MCP 与联网
  → 正文直写与审阅（v0.2）
  → 第三方执行隔离
  → 本机可执行 MCP
  → 废纸篓删除与恢复核验
  → 专项模型分工
  → 最终视觉与压测校准
```

新阶段是**产品与呈现重构**，不阻塞已交付的隔离分支；它把旧正文身份层替换为纯正文、修订与独立账本。
